Welcome to the Turkish Buddy, currently on Version 2.3!
To begin learning, select the "Practice" or "Test" button to be given a random set of either type.
(highly recommended to do all the practices first (even if you know Turkish, because of Turkish-English prepositions being weird))

In Practice, you will be given three Turkish sentences with English translations, followed by an English sentence you are tasked with translating to Turkish.
In Test, you will be given one Turkish sentence and be tasked with translating it to English with no context sentences.

Above the buttons, there are input boxes where you can input specific practice or test sets by selecting either button.
Keeping them blank/using invalid set will lead to the button selecting a random set as usual.
Below the buttons, there is a text box, where you should submit your answers using Turkish special characters.

Turkish special character letter bank (if you need to copy-paste):
ö ü ı ç ş ğ
